Data and AI Engineer, Decision Enablement

Standard Bank CIB Transaction Banking · Johannesburg · through the practice · concluded August 2026

  • Built the Python medallion pipeline behind a transaction banking intelligence platform on AWS S3 with Apache Iceberg, including a quality-control zone that stopped failures reaching gold tables.
  • Rebuilt three mainframe relationship-manager reports in SQL and reconciled each to source at record level.
  • Engineered training and serving pipelines for propensity, fraud and next-best-action models, and ran their MLOps deployments. Turned executive KPI definitions into ODCS/Bitol data contracts, so service-level breaches surfaced automatically rather than at month-end.
  • Built the retrieval and agent layer on LangChain and LangGraph, with Weaviate vector storage and Langfuse tracing, so every generated answer carried an evidence trail back to its source records.
  • Designed a neurosymbolic approach to AI determinism: LLM inference constrained by GoRules decision models and OpenSpec contracts, so identical inputs produce identical, explainable outputs.
  • Stood up the data and AI governance layer: model and prompt registries, evaluation and drift monitoring, human sign-off gates and a decision audit trail, alongside architecture board retrofit analysis and the service-account architecture for an assistant on Amazon Bedrock. Engineering was done with Claude Code, Cursor and Kilo Code under human review.
