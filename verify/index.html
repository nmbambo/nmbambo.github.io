Verify a certificate

Check that a report is genuine, whether it is the latest version, and, with its certified file, that nothing in it was changed.

I Check

For example IQX-DMSC-7K3M9QPA-V2. It is printed on every page of the report.

The .ingqiqo.json file downloaded with the report. It is checked in your browser and is not uploaded.

II What a valid result means

  1. The certificate ID is in Ingqiqo's register, and the register's copy still carries a signature only Ingqiqo can produce.
  2. With the file: the content you hold is byte for byte the content that was certified.
  3. It does not mean Ingqiqo has verified the answers in a self-check. Each report states its basis: self-reported, or scored by an assessor from evidence.
  4. A certificate whose holder asked for their data to be erased shows as withdrawn.
